🎨 CSS Border

Памятка по рамкам и их свойствам

🔹 Что такое border?

border — это рамка вокруг HTML-элемента. С помощью CSS можно задать её толщину, стиль, цвет, скругление и отдельно настроить каждую сторону.

Базовая запись состоит из трёх частей:

border свойство
(рамка)
:
4px толщина
solid стиль линии
#FF0000 цвет
;
Вот что получится на странице

🔸 Основные свойства border

border-width

Определяет толщину рамки. 

border-width: 3px;

border-style

Определяет стиль рамки. 

border-style: dashed;

border-color

Определяет цвет рамки. 

border-color: red;

border-radius

Скругляет углы рамки. 

border-radius: 10px;

⚡ Сокращённая запись

Вместо трёх отдельных свойств можно записать всё одной строкой в любом порядке. 
border: 2px solid red;

Или

border: red 2px solid;

Это все равно что:

border-width: 2px;border-style: solid;border-color: red;

🔸 Рамка для каждой стороны

Можно настроить верхнюю, правую, нижнюю и левую границы независимо друг от друга. 
border-top: 2px solid red;border-right: 3px dashed green;border-bottom: 4px dotted blue;border-left: 5px double purple;
Каждая сторона имеет свою рамку

🎯 Border в действии

Наводи курсор или нажимай на элементы. Справа подсветится CSS-код, который отвечает за изменение рамки.

Демонстрация

border-style
Наведи на меня
:active + border
Нажми и удерживай

💡 При нажатии рамка меняется на double.

border-radius
Наведи на меня
Рамки по сторонам
4 стороны — 4 разных border
Выбери элемент, чтобы увидеть соответствующий CSS-код.

CSS-код



.box:hover {
  border-style: dashed;
}

.box:active {
  border-style: double;
  transform: scale(.98);
}

.box:hover {
  border-radius: 25px;
}

.box {
  border-top: 4px solid red;
  border-right: 4px dashed green;
  border-bottom: 4px dotted blue;
  border-left: 4px double purple;
}

🔹 border-radius

border-radius задаёт радиус скругления углов. Чем больше значение, тем сильнее скругление. 
border-radius: 0;border-radius: 10px;border-radius: 50%;

Значение 50% часто используется, чтобы сделать круг из квадратного элемента.

⚡ Запомни:

border

Отвечает за рамку элемента.

border: 2px solid red;

border-radius

Отвечает за скругление углов.

border-radius: 10px;

Полная запись может выглядеть так: 

.box {
  border: 3px solid #6366f1;
  border-radius: 12px;
}
